# A Simple component based text terminal UI library

## Introduction

Environment prerequisition: Terminal (emulator) must support TTY.

### Basic features

 - Support basic CSS flow box like layout
 - Components are organized in a tree hierarchical structure
 - Dynamicall repaint content changes, including component hierarchical structure changes, text content changes
 - Support colorful font in ANSI escope code
 - Support long text wrap in constrained size
